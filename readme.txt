MHD FERDIANSYAH BLOG
=============

A clean, centered personal blog theme for WordPress with large, readable typography and a writing-focused homepage.

FEATURES
--------
- One-column writing-focused layout
- Homepage shows the latest posts directly
- No featured images in post listings
- Clean post metadata: date and author
- Responsive navigation
- Dark mode with local browser preference
- RSS link in the header
- Custom logo support
- WordPress Custom Menu support
- Search, archives, categories, tags and pagination
- Clean single-post reading layout
- No external CSS or JavaScript dependencies

INSTALLATION
------------
1. Go to WordPress Dashboard > Appearance > Themes.
2. Click Add New > Upload Theme.
3. Upload the mhdferdiansyah-blog.zip file.
4. Activate the theme.
5. Go to Settings > General and set your Site Title and Tagline.
6. Go to Appearance > Menus and create a menu named Primary Menu.
7. Create an About page with the slug "about" if you want the "More about me" link.
8. Optional: add GitHub and LinkedIn links through the Customizer if those settings are available in your WordPress installation.

CUSTOMIZATION
-------------
The main visual settings are in style.css.

The homepage intro uses:
- WordPress Site Tagline as the large heading.
- The "ferdi_intro_text" theme setting when available.

Post featured images are supported by WordPress but intentionally not displayed in the homepage/blog feed. They can still be inserted inside individual posts through the WordPress editor.
